# Olin HAIR Lab website

This repository contains the source code for the Human-centered AI and Robotics (HAIR) Lab website.

## How to run the website locally
This website is built with Jekyll. To run the website locally, follow the installation steps [here](https://www.taniarascia.com/make-a-static-website-with-jekyll/#installing-jekyll).


Then run
```bash
bundle exec jekyll serve
```
