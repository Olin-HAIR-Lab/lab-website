# Olin Field Robotics Lab website

This repository contains the source code for the Olin Field Robotics Lab website.

## How to run the website locally
This website is built with Jekyll. To run the website locally, follow the installation steps [here](https://www.taniarascia.com/make-a-static-website-with-jekyll/#installing-jekyll).

Make sure Ruby and Bundler are installed first. If `bundle` is not available, install Ruby, then run:
```bash
gem install bundler
bundle install
```


Then run
```bash
bundle exec jekyll serve
```
